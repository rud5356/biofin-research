# 2024년 BIOFIN 학습·예측 시연 (사업설명자료 포함)

10건으로 입력 → 원문 읽기 → 분류 → 귀속 예산 계산 과정을 보여줄 수 있습니다. 다만 10건 또는 본 폴더의 30건 학습은 기능 점검용으로, 성능 검증이나 운영 모델 구축용이 아닙니다.

## 파일 선택

| 파일 | 용도 |
| --- | --- |
| train_2024_30.csv | Transformer 학습: 카테고리 0~9 각각 3건 |
| predict_2024_10.csv | Transformer·LLM 공통 예측: 카테고리별 1건, 정답 제거 |
| answer_2024_10.csv | 발표자 정답 대조용. 예측 입력에는 사용하지 않음 |
| 사업설명자료_학습/ | 학습 30건의 사업설명자료 원문(HWP) 30개 |
| 사업설명자료_예측/ | 예측 10건의 사업설명자료 원문(HWP) 10개 |
| source_manifest.csv | 40건의 원본 CSV 행 번호, 정답 출처, 원문 파일명 |
| validation.json | 원본 해시, 건수, 중복 검사, 원문별 본문·사업목적 추출 글자 수와 해시 |
| SCENARIO.md | 실행 순서·명령어·발표 멘트 |

출처는 `document/20261101_2024.csv`와 `crawlers/open_fiscal/outputs/2024/사업설명자료/`입니다. 회계연도 2024, `gold_match_status=MATCHED`, 현재 LLM의 11개 대상 기관에 속하는 행만 골랐습니다. 원본 순서대로 카테고리별 서로 다른 사업 4건을 선택해 첫 1건은 예측, 나머지 3건은 학습에 배정했습니다. 원문 파일이 있고, 본문과 사업목적이 실제로 추출되는 사업만 선택했습니다. 정답 미매칭 시 자동 0으로 채워진 행은 제외했습니다. 정답은 기존 자료의 값을 보존했으며 이번에 독립 재판정하지 않았습니다.

원본 예산액은 열린재정의 백만원 단위입니다. CSV의 `사업설명자료_상대경로`는 CSV 위치 기준(`사업설명자료_학습/…`, `사업설명자료_예측/…`)이라 폴더째 옮겨도 LLM이 원문을 찾습니다.

## 문서 폴더를 나눈 이유

Transformer 학습은 문서 폴더 전체를 읽고 사업명 부분일치로도 정답을 붙입니다. 한 폴더에 두었을 때 예측용 `가축방역대응지원`·`농산물안전성조사(ODA)` 원문이 학습 사업 `가축방역`·`농산물안전성조사`의 정답(9번)으로 학습에 들어갔습니다. 그래서 학습·예측 원문을 분리했습니다. 학습에는 `사업설명자료_학습`만 지정하세요.

학습·예측 사업 그룹(소관명+세부사업명)은 겹치지 않지만, 위 두 쌍처럼 이름이 비슷한 사업은 있습니다. 특히 `농산물안전성조사(ODA)`는 정답 1번, `농산물안전성조사`는 9번으로, 비슷한 사업도 분류가 다를 수 있다는 설명에 쓸 수 있습니다. 기존 모델이 이 2024년 사업을 이미 학습했는지는 별도 확인해야 하므로 기존 모델의 시연 결과를 미학습 데이터 성능이라고 설명하면 안 됩니다. 카테고리 균등 표본이므로 실제 전체 예산사업 분포도 대표하지 않습니다.

Transformer는 기본 8:1:1 그룹 분할을 사용합니다. 30건은 일부 검증·시험 클래스가 빠질 수 있으며 점수가 크게 변동합니다. 분할 결과는 `split_summary.json`에서 확인하세요. LLM 메뉴의 ‘학습’은 동일 분류 스크립트 실행으로, 모델 가중치를 갱신하는 파인튜닝이 아닙니다.

CSV는 UTF-8 BOM 형식입니다. 폴더 전체를 서버의 프로젝트 루트 아래 `EXAMPLE`로 복사하세요(원문 포함 약 14MB). `build_examples.py`는 원본 CSV·원문 폴더로 동일 예시를 재생성합니다. 기존 운영 데이터·모델은 수정하지 않습니다.

## 로컬 확인 결과 (2026-11-04)

- CSV 생성 검증: 학습 30건·예측 10건, 카테고리별 3건·1건, 사업 그룹 중복 0건, 원문 40개 해시 일치.
- 원문 추출: 40개 모두 본문(1,439~36,246자)과 사업목적(91~1,091자) 추출 확인.
- Transformer `--dry_run` 통과: 문서 30개·정답 30건 모두 원문 매칭, 예산정보 대체 0건, 실패 0건, 카테고리별 3건. 클래스별 소량 경고는 이 예시의 구성에 따른 것입니다.
- LLM `--dry-run` 통과: 10건 모두 LLM 처리 대상, 사업설명자료 연결 10건·미발견 0건, 기관 제외 자동 0은 0건, 정답 없는 예측 입력으로 인식.
- 실제 분할 점검은 로컬 `scikit-learn` 미설치로 실행하지 못했습니다. 서버에서 분할 결과를 확인해야 합니다.
- 실제 모델 학습·예측과 LLM 서버 호출은 수행하지 않았습니다. 원문이 들어가 입력이 길어졌으므로 서버 리허설로 모델·의존성·실행 시간과 결과를 확인하세요.
