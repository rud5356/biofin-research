# 문서 폴더 규칙

기존 증강 데이터는 `document/열린재정/2023_aug/aug_2023_400_v2/`에 보관합니다. 일반 문서 자동 선택은 숫자 연도 폴더만 사용하므로 `_aug` 폴더는 제외됩니다. `config.json`의 `AUGMENTATION_ARCHIVE_DIR`는 증강 통합 CSV 사용을 명시적으로 선택했을 때 CSV를 찾을 폴더입니다. 여기서도 CSV가 하나면 자동 선택하고 여러 개면 선택 목록을 표시합니다. 설정을 바꾸어도 실제 폴더를 이동하거나 학습에 자동 포함하지 않습니다.

현재 서버의 `augmentation` 폴더 전체가 이 증강 데이터라면 그 폴더를 `열린재정/2023_aug/aug_2023_400_v2`로 옮깁니다. 이미 내부에 `aug_2023_400_v2` 하위 폴더가 있다면 그 하위 폴더만 옮깁니다. `EXAMPLE`은 그대로 둡니다.

메뉴에서 실행하는 크롤링과 학습·예측이 공통으로 사용하는 구조입니다. 기존 자료는 자동 이동하지 않습니다.

```text
document/
├─ 열린재정/
│  └─ 2024/
│     ├─ open_fiscal_2024.csv
│     └─ 사업설명자료/
└─ 지방재정/
   └─ 2024/
      ├─ gangwon/
      │  ├─ 2024_gangwon.csv
      │  └─ 사업설명자료/
      └─ ulsan/
         ├─ 2024_ulsan.csv
         └─ 사업설명자료/
```

기존 `document/2024/`의 내용은 `document/열린재정/2024/`로, `document/2024_gangwon/`의 내용은 `document/지방재정/2024/gangwon/`으로 옮깁니다. 문서 파일명은 바꾸지 않습니다. PDF·HWP 등 문서는 항상 연도/지역 폴더 아래의 `사업설명자료/`에 넣습니다. CSV는 연도/지역 폴더 바로 아래에 둡니다. CSV는 선택한 파일 안의 문서 경로가 새 문서 폴더 기준과 일치하는지 확인하세요.

학습·예측에서는 자료 구분 → 연도 → 지역(지방만)을 선택하면 문서 폴더가 자동 지정됩니다. 지정 폴더 바로 아래 CSV가 하나면 자동 선택하고 여러 개일 때만 파일 목록에서 선택합니다. 열린재정 Open API는 CSV만 저장하므로 상세 문서는 별도 수집해야 합니다. `CRAWL_LIST_ONLY`가 true인 경우도 문서는 수집하지 않습니다.

크롤링 메뉴는 대상·연도·지역을 선택한 뒤 위 규칙에 맞는 `--save-dir` 또는 `--manifest`·`--output-dir`을 크롤러에 전달합니다. 크롤러를 직접 실행할 경우에도 이 경로를 지정해야 합니다. 실행 전 명령어에서 저장 경로를 확인할 수 있습니다.

## 학습·예측 결과 폴더

결과 경로는 `<모델종류>/<OUTPUT_SUBDIR>/오늘날짜_선택연도_자료구분_번호`로 자동 지정합니다. 날짜는 한국 시간 기준 YYYYMMDD입니다. 예: `llm/v1/outputs/20261111_2024_열린재정_1`. 같은 접두사의 파일·폴더가 있으면 최대 번호 다음 값을 사용합니다. 지방재정도 지역명 없이 `20261111_2024_지방재정_1`처럼 저장합니다. 증강 작업의 결과 폴더 선택은 기존 방식을 유지합니다.

## 예측에 사용할 학습 모델

Transformer 예측은 `transformer/v1/outputs/20261102_2023_train`을 자동 사용합니다. 다른 모델로 바꾸려면 `config.json`의 `TRANSFORMER_MODEL_DIR`를 수정합니다. 새 학습 결과는 기존 날짜·연도·자료구분·번호 규칙으로 저장되며, 예측 모델 설정은 자동 변경하지 않습니다.
