# BIOFIN 실행 도우미

Linux 호스트의 Python 3.8 이상과 Docker가 필요합니다. Python 패키지 추가 설치는 없습니다.

`biofin_menu.py`, `config.json`, `defaults.json`을 함께 Linux의 `~/biofin/biofin_cls3/`에 복사하고 실행합니다.

```bash
cd ~/biofin/biofin_cls3
python3 biofin_menu.py
```

시작 메뉴는 **1. 모델 예측 → 2. 모델 학습 → 3. 크롤링 → 4. 데이터 증강** 순서입니다. 작업과 모델을 고른 뒤 자료 구분·연도·지역으로 자료 폴더를 지정합니다. 사업설명자료 하위 폴더와 CSV 한 개는 자동 지정되며 CSV가 여러 개일 때만 선택 목록을 표시합니다. 학습·예측 결과 폴더는 자동 지정하고, 예측 모델은 `config.json`의 `TRANSFORMER_MODEL_DIR`를 자동 사용합니다.

Transformer 학습에서는 원본만 사용할지, 원본+증강 통합 CSV를 사용할지 선택합니다. 통합 CSV는 `build_merged_training_csv.py`로 만든 `row_type`, `training_eligible` 컬럼이 있는 UTF-8 파일입니다. `defaults.json`의 `TRAIN_AUGMENTATION_PER_CLASS`에서 증강 상한을 정합니다(null: 전체). 원본만 선택하면 `--augmentation_per_class 0`을 전달합니다. 4번 데이터 증강 메뉴에서는 원본+증강 합계가 가장 적은 카테고리부터 50개씩 생성해 모든 카테고리가 `AUGMENTATION_TARGET`(기본 400)개가 되면 종료하며, 실행 전에 서버 저장 경로를 표시합니다.

vLLM은 KT Cloud 등에서 이미 기동한 모델에 API로 분류를 요청합니다. API URL과 모델 ID는 `config.json`, 문자 수·토큰 수·동시 요청 수·타임아웃은 `defaults.json`에서 읽어 명령어에 자동 반영합니다. GPU 점유·최대 컨텍스트·서버 동시 시퀀스 설정은 변경하지 않습니다. 인증이 필요하면 호스트의 `VLLM_API_KEY` 환경변수가 컨테이너로 전달됩니다. vLLM은 버전을 묻지 않고 항상 V2 프롬프트(분류지침 개정 2026.10.22 반영) `llm/v1/classify_biofin_category_with_vllm_V2.py`를 실행하며, 이 파일이 프로젝트에 있어야 합니다. 실행 스크립트는 `config.json`의 `VLLM_SCRIPT`에서 바꿀 수 있습니다.

모델 예측은 분류 → 귀속 예산(BAR) 계산까지 이어서 실행하고, 끝나면 결과 폴더에 `*_bar.csv`와 히트맵 파일만 남깁니다. 이번 실행에서 생긴 중간 파일(분류 원본 CSV, 요약·캐시·검수·평가 파일 등)은 삭제하며, 실행 전부터 폴더에 있던 파일은 지우지 않습니다. `*_bar.csv`가 만들어지지 않으면 아무것도 지우지 않습니다.

- `0`: 상위 폴더로 이동
- `s`: 현재 폴더 선택 (문서·모델·결과 폴더)
- `n`: 현재 위치에 새 결과 폴더 지정 (결과 폴더 선택 화면). Enter를 누르면 자동 날짜 이름을 사용합니다.
- `q` 또는 Ctrl+C: 취소

프로젝트 밖으로는 이동할 수 없고 숨김 항목은 표시하지 않습니다. 새 결과 폴더는 선택 시 생성하지 않고 기존 실행 스크립트가 생성합니다. 실행 변수는 별도 질문 없이 설정 파일의 기본값을 사용합니다. 마지막 확인에서 `y`를 입력해야 실행됩니다.

다른 위치에서 실행하거나 명령어만 확인하려면:

```bash
python3 biofin_menu.py --project-dir ~/biofin/biofin_cls3 --dry-run
```

입력 경로는 호스트 프로젝트 안의 경로입니다. Transformer는 호스트와 컨테이너 내부(`/work/biofin_cls3`)가 같은 프로젝트 파일을 가리켜야 합니다. 기존 `biofin` 컨테이너가 실행 중이어야 합니다. LLM은 프로젝트를 `/workspace`에 마운트하고 호스트 UID/GID로 실행합니다. 기존 `.packages` 의존성 및 선택한 Ollama 또는 vLLM 서버/모델이 준비되어 있어야 합니다.

제공된 LLM 학습과 예측은 같은 분류 스크립트를 실행합니다. 별도의 파인튜닝 명령어는 포함하지 않았습니다. 재시도 횟수는 `defaults.json`의 `RETRIES`(기본 1)를 항상 명령어에 넣습니다.

결과 폴더 생성과 실제 출력 파일 처리는 기존 모델 스크립트가 수행합니다. 호스트에서 컨테이너용 결과 폴더를 미리 생성하지 않습니다.

## 자료 수집 (크롤러)

작업 선택에서 `3. 크롤링`을 고르면 수집 대상 → 연도 → 지역(지방재정만)을 선택합니다. 저장 경로는 아래 규칙으로 자동 지정하며, 범위·한도는 `defaults.json`에서 읽습니다. Transformer 학습·예측과 같은 `biofin` 컨테이너 안에서 실행합니다.

준비:

- 저장소의 `crawlers/` 폴더를 프로젝트 폴더에 복사합니다 (`~/biofin/biofin_cls3/crawlers/`).
- `.env.example`을 `~/biofin/biofin_cls3/.env`로 복사하고 Open API 인증키를 넣습니다. 인증키가 없으면 5건까지만 받을 수 있습니다.
- `biofin` 컨테이너가 실행 중이어야 하고, 호스트 프로젝트와 컨테이너 내부 프로젝트(`/work/biofin_cls3`)가 같은 폴더를 가리켜야 합니다.

상세 PDF나 사업설명자료 수집에는 컨테이너에 Playwright와 Chromium(열린재정은 pandas, openpyxl, tqdm도)이 필요합니다. 실행 직전에 메뉴가 자동으로 확인하고, 없으면 설치할지 물어본 뒤 컨테이너 안에 설치합니다. 컨테이너를 새로 만들면 설치한 내용이 사라지므로 그때는 다시 물어봅니다. 지방재정365 목록과 열린재정 Open API 예산 목록은 추가 설치 없이 동작합니다.

수집 결과는 모두 프로젝트의 `document/` 아래에 저장됩니다.

| 수집 대상 | 저장 위치 |
|---|---|
| 지방재정365 | `document/지방재정/<연도>/<영문지역>/<연도>_<영문지역>.csv`, 같은 폴더의 `사업설명자료/` |
| 열린재정 | `document/열린재정/<연도>/open_fiscal_<연도>.csv`, 같은 폴더의 `사업설명자료/` |
| 열린재정 Open API 예산 목록 | `document/열린재정/<연도>/open_fiscal_api_<연도>.csv` (문서 수집 없음) |

지방재정365는 `CRAWL_REGIONS` 목록에서 한 지역을 선택해 수집합니다. 지역별로 각각 실행하여 자료가 섞이지 않도록 합니다. 기존 폴더가 있으면 경로를 표시하고 최종 실행 확인 후 크롤러의 이어받기 규칙을 적용합니다.

학습·예측의 사업설명자료 선택도 **열린재정/지방재정 → 연도 → 지역(지방만)** 순서입니다. 위 저장 위치의 `사업설명자료` 폴더를 자동 지정합니다. 문서는 반드시 해당 폴더 아래의 `사업설명자료/`에 보관합니다. 폴더가 없거나 문서가 없으면 실행 전에 안내합니다. 지정 폴더 바로 아래 CSV가 하나면 자동 선택하고 여러 개면 파일 목록에서 선택합니다. CSV가 없으면 오류를 안내합니다.

17개 시도의 영문 폴더명과 기존 자료 이동 예시는 [문서 폴더 규칙](문서_폴더_규칙.md)에 있습니다. `REGION_CODES`는 수집과 문서 선택에 공통 적용됩니다.

## 실행 기본값 설정

스크립트와 같은 폴더의 두 설정 파일을 수정하고 메뉴를 다시 시작하면 적용됩니다.

- `config.json`: 자주 바꾸는 입력·모델 경로, 서버 URL·모델 ID, 귀속률 파일을 위쪽에, 프로젝트·Docker·스크립트 경로 등 초기 환경 설정을 아래쪽에 배치했습니다.
- `defaults.json`: 예측·학습·크롤링·증강의 실행 변수 기본값입니다. 토큰 수, 동시 요청 수, 학습률·에포크·배치, 학습 가중치, 수집 연도·지역·한도, 증강 API·목표 개수 등을 여기서 수정합니다.

각 항목 바로 위의 `_comment_항목명`은 설명용 주석입니다. 표준 JSON 호환성을 유지하기 위한 문자열 항목으로, 프로그램은 이를 무시합니다. 실제 값은 바로 아래 항목에서 수정합니다. `//` 주석은 사용하지 않습니다.

파일·폴더, 작업, 모델 종류, 학습 데이터 종류, 수집 대상은 메뉴에서 선택합니다. 그 외 실행 변수는 기본값을 명령어에 자동으로 넣으며 실행 전 전체 명령어를 표시합니다. `--dry-run`으로 실제 실행 없이 확인할 수 있습니다. Boolean 옵션은 true일 때 플래그를 추가하고 false일 때 생략합니다. 증강 학습 상한 null은 전체 사용을 뜻하므로 상한 옵션을 생략합니다.

`PROJECT_DIR`의 null은 현재 작업 폴더, `CRAWL_YEAR`의 null은 전년도, `CRAWL_DATE`의 null은 해당 연도 12월 31일입니다. API 키 실제 값은 환경변수나 `.env`로 관리합니다. 설정 파일이 없거나 JSON 형식이 잘못되면 오류를 안내합니다.

분류 규칙 파일 `budget_biodiv_cls3/pipeline/config.json`과는 별개입니다.
